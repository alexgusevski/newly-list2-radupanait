# Contributing to Awesome AI Hosting

Thank you for your interest in contributing! This list is a community effort, and we appreciate your help keeping it up to date.

## Guidelines

### Adding a new entry

1. Make sure the platform/tool is related to AI coding agents or AI-powered development.
2. Search existing entries to avoid duplicates.
3. Use the following format:

```
- **[Name](https://url.com)** — Short description of what it does.
```

4. Keep descriptions concise (one sentence, under 150 characters if possible).
5. Add the entry to the appropriate section in alphabetical order (except where noted).
6. Make sure your links are working and point to the official website.

### Updating an existing entry

- If a platform has changed significantly (rebranded, shut down, pivoted), please submit a PR with the update.
- If a link is broken, please fix it or flag it in an issue.

### What we are looking for

- Platforms for hosting AI coding agents (Claude Code, Codex, etc.)
- Cloud IDEs with meaningful AI integration
- AI app builders that generate and deploy code
- Container/serverless platforms suitable for AI workloads
- Self-hosted tools for running AI coding agents

### What we are NOT looking for

- General AI/ML model hosting (e.g., model serving platforms)
- AI chatbots or conversational AI platforms
- Tools unrelated to software development

## Pull Request Process

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes following the guidelines above.
4. Submit a pull request with a clear description of what you added or changed.

## Code of Conduct

Be respectful and constructive. We are all here to build a useful resource for the community.
